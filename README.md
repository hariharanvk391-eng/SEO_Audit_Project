# SEO_Audit_Project


## Project Overview

This project is an **SEO Checklist and Website Audit Report** created for analyzing the SEO performance of the SAP India website.

The report covers important SEO metrics such as:

* Organic & Paid Traffic
* Organic & Paid Keywords
* Backlinks Analysis
* Keyword Rankings
* Broken Links
* Mobile Responsiveness
* Core Web Vitals
* Bounce Rate
* Domain Authority (DA)
* Page Authority (PA)
* Domain Rating (DR)
* Referring Domains
* Top Keywords & Top Pages
* Keyword Difficulty
* Branded vs Non-Branded Traffic
* Backlink Types
* Keyword Gap & Backlink Gap
* New & Lost Referring Domains
